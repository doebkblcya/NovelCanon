# ADR-0001 运行时与包管理

- 状态：已接受（2026-08）
- 适用范围：全局工程基线

## 背景

阶段 01 需要确定语言运行时与包管理方式。候选：Python 3.12 / 3.13 / 3.14，uv / poetry / pdm。

## 决策

- 语言基线：`requires-python = ">=3.13,<3.15"`，生产默认 **Python 3.13**，CI 增测 **3.14**；
- 包管理：**uv**（`pyproject.toml` + `uv.lock`，构建后端 hatchling）；
- 暂不支持 3.12；不使用尚未正式发布的 3.15。

## 理由

- Python 3.12 已进入仅安全修复阶段，3.13 / 3.14 处于 bugfix 阶段，新项目不把 3.12 作为推荐基线；
- sqlite-vec 0.1.9 发布的是 `py3-none-*` wheel（平台相关、不绑定 CPython ABI），不存在"3.13 不兼容该 C 扩展"的问题；
- uv 安装快、锁文件可复现，一条命令管理 venv、依赖与工具链，CI 开销低。

## 后果

- 全部代码按 3.13 语法与行为编写；CI 同时验证 3.14 兼容性；
- 引入依赖时必须确认存在 3.13/3.14 可用 wheel；
- 所有精确版本以 `uv.lock` 为准，不手工维护 requirements 文件。
