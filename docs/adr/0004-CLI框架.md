# ADR-0004 CLI 框架

- 状态：已接受（2026-08）
- 适用范围：CLI 入口（阶段 01 实现骨架）

## 背景

定版方案需要统一命令行入口：`import / index / extract / activate / query / inspect`。

## 决策

- **Typer**（基于 Click，类型提示自动生成帮助与补全）；
- 命令集固定为六个：`novelcanon import`、`index`、`extract`、`activate`、`query`、`inspect`；
- CLI 只做参数解析与调用 application service，不直接编写 SQL 或业务逻辑；
- 未实现命令明确返回"尚未实现"，不得静默通过；
- 未来 API 与 CLI 复用同一 service 层（service 层阶段 02 起逐步建立）。

## 理由

- Typer 与 Pydantic/FastAPI 同生态，声明式命令定义，测试友好（CliRunner）；
- 固定命令边界保证阶段 06–11 新增实现时不改入口结构。

## 后果

- 新增命令或子命令须在 01 文档的退出标准内保持入口兼容；
- CLI 无网络、无模型密钥可运行（01 退出标准）。
