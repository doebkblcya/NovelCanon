# NovelCanon 文档

本目录包含 NovelCanon 的技术方案、阶段文档、ADR 和前期项目研究报告。项目实现以《定版方案》为准，研究报告仅用于追溯设计来源与工程约束。

## 核心文档

| 文档 | 内容 |
|---|---|
| [定版方案.md](定版方案.md) | 系统边界、数据模型、处理流水线、检索设计、Token 预算、验收标准和实施阶段 |
| [00-项目研究文档](00-项目研究文档/README.md) | 前期项目调研、设计来源和工程约束 |
| [01-工程实现阶段](01-工程实现阶段/README.md) | 阶段 01–11 的工程实现记录；基础机制已交付，未完成验收项已结转 |
| [02-质量验收与产品化阶段](02-质量验收与产品化阶段/README.md) | 当前阶段：质量基线、图谱产品面、查询 LLM、压缩决策和长篇规模化路线 |
| [ADR](adr/) | 已冻结的关键技术决策及其背景 |

## 阅读顺序

1. 阅读 [定版方案.md](定版方案.md)，掌握当前实现契约。
2. 阅读 [当前阶段路线图](02-质量验收与产品化阶段/README.md)，确认优先级、依赖和验收门。
3. 需要追溯已实现能力时，阅读 [工程实现阶段](01-工程实现阶段/README.md)。
4. 按需要查阅[项目研究文档](00-项目研究文档/README.md)，确认具体设计来源和许可证边界。
5. 数据结构、接口或实现发生变化时，先修改定版方案，再更新代码和阶段文档。

## 文档约定

- `claim`：可验证的结构化事实。
- `evidence`：支持、反驳或无法判断某条事实的原文片段。
- `observed`：信息在文本中被披露的章节位置。
- `world_valid`：信息在故事世界中的有效时间；无法确定时保持未知。
- `canonical`：完成跨章实体消歧后的稳定标识。
- `as_of_chapter`：查询可见信息的最大披露章节。
