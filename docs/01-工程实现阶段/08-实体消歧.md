# 08 实体消歧

## 目标

将跨章 mention 映射为稳定 canonical entity，同时保留 unresolved、合并/拆分审计，并确保查询不会通过最终实体名称泄露后续情节。

## 前置条件

- entity mention、alias claim 和 merge audit 表可用。
- Map Draft 已稳定产出 mention 和上下文。
- 证据能够定位到原文章节。
- 准备同名、别名、称谓变化和后期身份揭示样例。

## 基本原则

- canonical_id 不依赖名称、ordinal 或 extraction run。
- entity 表只保存内部 canonical name，不复制 aliases。
- alias 必须以带 observed ordinal 和证据的 claim 保存。
- unresolved 是正式流水线产物，不是可忽略的错误字符串。
- EventLinker 只消费已经完成 canonical 映射的数据。

## 实施顺序

### 1. 名称规范化和泛称过滤

- 统一全半角、空白和可安全归一的标点。
- 保留 surface name，不丢失原文写法。
- 识别“男子”“长老”等泛称，避免直接创建错误实体。
- 世界内纯概念与参与结构化关系的实体分开处理。

### 2. 确定性规则

优先处理：

- 已验证的精确 alias；
- 同章明确同位语；
- 明确身份声明；
- 唯一候选的规范化名称；
- 人工锁定的 merge/split 规则。

规则决策必须记录 resolver version 和依据。

**确定性层 v3（验收 P0 收紧）**：

- canonical_id = ent_<hash(book_id, 首提及锚点)>——锚点为组内首个 mention
  的章节位置（chapter_id + char_start + char_end）。不依赖名称（身份揭示
  改名不换 ID）、不依赖 ordinal / extraction run；不同书同名人物不共享 ID。
- **稳定锚点落库**：materialize 把 mention 的章节内字符位置（surface 在
  章内首次出现，标点/空白容差）写入 entity_mentions——canonical ID 由
  book + chapter + span 生成，不依赖 LLM 生成的 mention_id（重新抽取时
  本地 ID 变化不得导致 canonical 漂移）。
- 同 surface 归组：同章多次提及 → 同一人物（合并，不再强制拆开）；
- 跨章连续（章节序无缺口）或任一章节出现 ≥2 次 → 同一人物（连续性信号）；
- 跨章孤立出现（每章一次且章节序不连续）→ 无法判断 → unresolved，
  不盲目合并「不同章节的两个同名人物」；
- 已验证精确 alias（seed）优先合并（身份揭示走 canonical 层）；
- **alias seed 过滤**：resolve_run 只 seed「已确认的历史 canonical alias」
  （经 entity_resolutions 投影到最终 canonical），排除本轮 materialize
  为每个 mention 写入的临时 alias——否则同名实体直接走 seed-alias 合并，
  绕过 v3 的隔章歧义判断。

### 3. 候选生成

利用：

- 同章和邻章共现；
- 实体类型；
- 属性和状态兼容性；
- 关系邻域；
- alias 历史；
- 章节距离。

先召回有限候选，再评分；不得让模型在全书实体中自由生成答案。

### 4. 低置信语义判定

- 只向模型提供候选及必要上下文。
- 允许输出“不确定/新实体”。
- 设置自动合并、自动新建和 unresolved 的不同阈值。
- 模型判定保存 prompt/profile 和证据。

### 5. 第二遍复判

第一遍 unresolved 在全书上下文可用后再次处理：

- 汇总同 surface mention；
- 加入后续 alias 和属性信息；
- 重新生成候选；
- 仍不确定则进入人工标注队列。

### 6. 合并与拆分审计

- merge/split 不物理覆盖历史。
- 保存来源实体、目标实体、理由、证据、run 和版本。
- 提供重放或重建 canonical 投影的能力。
- 下游 claim 通过映射重写，不直接修改不可审计历史。

### 7. 知识截止名称

展示名称只能从满足以下条件的 alias claim 选择：

- book_id 匹配；
- observed_ordinal 不大于 cutoff；
- claim 为 supported；
- 对当前 canonical entity 有效。

无可见 alias 时使用截止前已披露的 surface name 或安全占位，不得回退到全书最终名称。

## 产物

- normalization/filter rules；
- candidate generator 和 scorer；
- semantic resolver；
- unresolved second pass；
- merge/split audit；
- cutoff-safe display name service；
- 实体消歧黄金集和指标报告。

## 验证

- canonical ID 在相同输入和配置下稳定。
- 同名不同人物不被规则误合并。
- 后期身份揭示可以在全书 canonical 层合并。
- 早期 cutoff 查询不会展示后期名称。
- unresolved 数量、占比和类型可统计。
- merge/split 决策均可追溯和重建。

## 退出标准

- 开发标注集达到预先冻结的阶段阈值；定版方案中的正式指标留到阶段 11 的 P1 验收。
- 全部 mention 都处于 canonical mapped 或 unresolved 之一。
- EventLinker 接收不到未映射实体。
- cutoff-safe 名称测试覆盖早期、中期和全书三个窗口。
