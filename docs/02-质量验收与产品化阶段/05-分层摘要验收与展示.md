# 05 分层摘要验收与展示

> 优先级：P1  
> 状态：分组、Reduce、版本失效和 LLM CLI 已实现；真实质量验收与产品展示待完成

## 目标

验证章节结构化记忆到卷摘要、全书摘要的真实质量、成本和 cutoff 安全性，并让摘要成为 API/前端可浏览的正式产品能力。

## 主要任务

1. 在已通过 Map 质量门的书上运行真实 LLM 分层摘要，冻结 generation profile 和 prompt 版本。
2. 为卷/全书摘要建立覆盖率、事实一致性、引用可追溯和未来信息泄露评测。
3. 验证输入 claim 变化后 stale 标记、依赖传播和重建行为。
4. 记录每级摘要 token、成本、耗时和失败重试。
5. 提供摘要列表/详情 API，在前端展示卷边界、摘要内容、版本和证据来源。
6. 明确确定性摘要、LLM 摘要和模型失败时的降级策略。

## 退出条件

- 真实书籍的卷/全书摘要通过人工抽查和冻结指标。
- 摘要中的事实可回到输入 claim 和原文证据，不产生无依据新增事实。
- `knowledge_cutoff` 下不读取或泄露后续章节摘要。
- API、CLI 和前端读取同一 active/valid 摘要版本。
- 输入变化、模型 profile 变化和 prompt 变化均触发正确失效或重建。
