# 03 实体图谱 API 与前端

> 优先级：P1  
> 状态：基础图书选择、查询和证据展示已完成；图谱产品面待实现

## 目标

让用户能够直接浏览数据库中的实体、属性、状态、关系、事件、因果链、章节图和摘要，并从每项知识回到原文证据。

## 建议实施顺序

1. 定义实体、关系、事件、图数据和摘要的只读 API 契约。
2. 实现列表、搜索、详情、分页及截止章节过滤。
3. 实现实体详情页和证据侧栏。
4. 实现属性/状态与事件时间线。
5. 实现人物关系图、事件因果图和章节图。
6. 补充空状态、无索引状态、歧义实体和运行版本提示。

所有读取必须遵守 `book_id`、active run、`knowledge_cutoff`、`world_at` 和证据版本隔离。图形展示不应绕过查询层直接拼接历史数据。

## 退出条件

- 用户无需 CLI 即可查找实体并浏览核心知识类型。
- 图上的节点和边可以展开查看来源章节与原文证据。
- 同名人物和未解决实体不会在界面上被静默合并。
- 关键页面有 API 和浏览器回归测试。
