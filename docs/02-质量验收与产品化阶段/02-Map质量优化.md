# 02 Map 质量优化

> 优先级：P0  
> 状态：等待未压缩基线

## 目标

根据黄金集暴露的具体错误优化抽取和下游物化质量，避免继续用 active claim 数量或少量人工样例代替内容验收。

## 优化范围

- Map Schema 与提示词遵循度；
- 逐字证据完整性与 claim 语义一致性；
- 同名人物、别名、代词和代际实体消歧；
- 属性、关系、状态、事件参与者与时间信息；
- 事件链接和因果方向；
- 修复后的局部重跑、版本隔离和历史可审计性。

## 执行原则

1. 先按 claim 类型和错误类型分析 Pilot，不盲目调整提示词。
2. 开发集用于修复，盲测集只用于阶段验收。
3. 每次修改记录模型、prompt、verifier 和 Schema 版本。
4. 优先复用已有 draft，只有 Map 输出确需改变时才重新调用 LLM。
5. 局部指标改善不能以其他类型明显退化为代价。

## 退出条件

- 达到黄金集冻结时确定的 precision、recall、F1 和证据指标。
- 核心错误类型有回归样例覆盖。
- 激活数据、证据版本、运行版本和评测输入可以相互追溯。
