# 04 查询 LLM 合成

> 优先级：P1  
> 状态：检索与底层合成契约已有；生产 LLM 接线和质量验收待完成

## 目标

在结构化查询和混合检索结果之上生成自然语言回答，同时保证回答可引用、证据不足时可拒答，且不会用流畅表达掩盖上游数据错误。

## 主要任务

- 为查询合成配置独立于 Map 的模型 profile；
- 统一 API 与 CLI 的生产 GenerationClient 生命周期；
- 限制模型只使用提供的上下文，输出结构化答案、引用和拒答原因；
- 记录 token、成本、延迟、重试和模型版本；
- 处理超时、配置错误、Prompt 注入和上下文溢出；
- 用冻结 QA 对比确定性回答与 LLM 合成回答。

## 退出条件

- 答案正确率、引用准确率和拒答准确率达到冻结阈值。
- 每个事实性回答都可以定位到返回的证据。
- 无证据、冲突证据和模型服务失败有明确降级行为。
- 缓存键包含数据 run、检索配置和合成 profile，版本变化不会复用旧答案。
