# 阶段二：质量验收与产品化

> 状态：进行中  
> 前置阶段：[阶段一：工程实现](../01-工程实现阶段/README.md)的工程基础已交付；未完成验收项在本阶段继续闭环。

## 阶段目标

本阶段把已经跑通的工程 Demo 推进为质量可测、数据可信、界面可用并能扩展到长篇小说的产品。工作不再以“功能是否存在”为主要判断，而以冻结评测集、可复现指标、用户可见能力和上线门禁为准。

## 依赖关系

```text
黄金集冻结
    ↓
未压缩基线 Pilot
    ↓
Map / 证据 / 消歧 / 链接修正
    ├──→ 实体图谱 API 与前端
    ├──→ 查询 LLM 合成与 QA 评测
    ├──→ 分层摘要验收与展示
    └──→ 压缩对照实验
                 ↓
        运维/索引性能门
                 ↓
        200–300 章规模 Pilot
                 ↓
             全量上线
```

实体图谱 API 和基础界面可以在人工标注黄金集期间并行开发，但正式演示和上线必须使用通过质量门的数据。查询 LLM 与压缩都不能替代上游数据质量验收。

## 阶段门禁

进入长篇全量运行前，至少满足：

1. 黄金集内容、版本和 hash 已冻结，评测过程不依赖人工临时判断。
2. 未压缩基线达到《定版方案》的 Pilot 阈值。
3. 关键实体、事实、事件和因果关系可从界面追溯到原文证据。
4. 查询 LLM 不脱离检索证据作答，引用和拒答都有独立指标。
5. 分层摘要已经过真实数据验证，能追溯输入版本且不会泄露 cutoff 后内容。
6. `inspect`、真实黄金持续回归和生产索引性能门已经闭环。
7. 压缩若启用，必须通过与未压缩基线的对照门；不通过则保持关闭。
8. 先完成 200–300 章规模验证，再运行超长篇全量抽取。
