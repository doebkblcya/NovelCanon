# 01 黄金集与质量基线

> 优先级：P0  
> 状态：待人工标注

## 目标

冻结一套不随模型输出调整的人工真值，并用当前未压缩流水线建立质量基线。它回答的不是“管线能不能跑”，而是抽取、消歧、事件链接和查询结果是否正确。

## 主要流程

1. 按冻结计划标注开发章节和盲测章节。
2. 覆盖事实与逐字证据、实体合并/禁止合并、状态与关系、事件、因果边和 QA。
3. 固定语料 hash、Schema 版本、模型 profile、阈值和评测参数。
4. 先运行未压缩 Pilot，保存逐项错误和总体指标。
5. 冻结基线报告，作为后续 Map、查询 LLM 和压缩实验的共同对照。

## 退出条件

- 生成并冻结可由程序读取的 `golden.json`。
- 开发集与盲测集边界明确，盲测答案在评测前不用于调参。
- Pilot 可重复运行并输出 claim、evidence、entity、event/link、retrieval/QA 分项指标。
- 基线报告包含失败样例，而不只包含汇总数字。
